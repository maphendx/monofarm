5.0Motion05 / 11

Motion

Motion is invisible until it's wrong. Three durations, four easings, two transition recipes. Nothing decorative — every animation reinforces state change.

Durations
--dur-instant
80ms

Hover, click feedback, color shifts. The eye barely registers it.

--dur-quick
160ms

Dropdowns, tooltips, toast enter/exit. Default for most UI.

--dur-base
240ms

Modal open/close, sidebar expand, panel slide. Feels deliberate.

--dur-slow
400ms

Page transitions, full-screen state changes. Reserved for moments.

Easings
--ease-out cubic-bezier(.16, 1, .3, 1)

Default for enter animations — fast start, gentle settle. Most things use this.

--ease-in-out cubic-bezier(.65, 0, .35, 1)

Two-way state transitions — toggle, accordion, hover-and-back.

--ease-spring cubic-bezier(.34, 1.56, .64, 1)

Tiny overshoot for delightful moments — "sent successfully" toasts, checkmark stamps.

--ease-linear linear

Progress bars, spinners, loops — only for continuous motion. Never for UI states.

Recipes
FADE + RISE

Toast, popover, dropdown enter

opacity 0 → 1
translateY +4px → 0
160ms ease-out
SCALE + FADE

Modal enter

scale .96 → 1
opacity 0 → 1
240ms ease-out
backdrop: 240ms linear
STAGGER

Printer card list reveal

delay: index × 24ms
(cap at 8 items, then instant)
240ms ease-out
PULSE · live

Status dot during "printing" / "alert"

scale 1 → 1.4 → 1
opacity .25 → 0 → .25
1.6s linear infinite
Principles
01 · Purposeful

Every animation answers "what changed?" — never decorates. If you can't explain the state shift, remove it.

02 · Fast

Operators click thousands of times a day. 80–240ms ceiling on UI feedback. Page transitions are the only place 400ms is allowed.

03 · Honor prefers-reduced-motion

Drop all motion to .01ms when the OS asks. Pulse on critical alerts remains — it's a legibility tool, not decoration.

9.4 · Design principles for the agent
01 · Native chrome

Use platform window controls (macOS traffic lights, Windows title bar). Never reinvent — desktop is not the web.

02 · Same tokens

All colors, type, spacing, radii are identical to the web app. No retraining the eye between contexts.

03 · Background-first

Default state is closed. Operator opens the agent only for diagnostics. Tray icon does 95% of the communication.

10.5 · Integration with farm
01 · Shared palette

Same cyan accent, same state colors. The state badge "in stock" reads identically to "ready" on a printer card. No mental context switch.

02 · Denser, not louder

Same tokens — but rows shrink to 36px height, font drops to 12.5px. Warehouse is for power users; farm is for at-a-glance.

03 · Bidirectional

Click any filament chip on a printer card → opens the SKU here. Click a SKU → see all printers currently using it. No dead ends.
